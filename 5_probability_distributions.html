Quiz 2: Binomial & Negative Binomial ✓ Done

Question 1: What does dbinom(5, size=5, prob=0.5) compute?

Question 2: A footballer scores 90% of penalties (p = 0.9) and takes 20 in training (L = 20). Using E(X) = L·p, the expected number of goals is 18. What do L and p represent in the binomial distribution?

Question 3: What does the negative binomial distribution describe?

Quiz 3: Poisson Distribution ✓ Done

Question 1: The Poisson distribution has a single parameter λ, with E(X) = Var(X) = λ. In the gene mutation example, what did λ represent?

Question 2: What does ppois(q = 10, lambda = 30) compute?

Question 3: On average 50 students attend a lecture. Which function computes the probability that exactly 60 students show up?

Quiz 4: Normal & t-Distribution ✓ Done

Question 2: What makes the standard normal distribution special?

Quiz 5: Relationships Between Distributions (Plenum) ✓ Done

Question 1: Under what condition does the Poisson distribution become approximately equivalent to a Normal distribution?

Question 2: A Binomial(n, p) distribution converges to a Poisson(λ = np) distribution under which condition?
