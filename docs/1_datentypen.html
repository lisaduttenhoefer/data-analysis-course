a   <- 2            # numeric
b   <- TRUE         # logical
name <- "Rosalinde" # character (string)

a + 3               # use in calculations: returns 5
print(name)         # explicitly print to console
Function What it does
str(x) Show structure and type of x
ls() List all objects in the environment
rm(x) Remove variable x from the environment
load("file.RData") Reload a saved environment

Vectors

Creating & accessing vectors

A vector is a sequence of values of the same type. When you mix types, R converts everything to the lowest common type (logical → numeric → character).

y <- c(9, 3, 7, 2)   # numeric vector of length 4
length(y)             # 4

# Indexing
y[3]          # 7        — third element
y[2:4]        # 3 7 2    — elements 2 to 4
y[-2]         # 9 7 2    — all except element 2
y[y < 5]      # 3 2      — elements where condition is TRUE

# Logical tests (applied to each element)
y < 5         # FALSE TRUE FALSE TRUE
sum(y < 5)    # 2  — count of elements satisfying condition

# Modifying
y[1] <- 10    # replace first element
TRUE / FALSE in arithmetic: R treats TRUE as 1 and FALSE as 0. So sum(c(TRUE, FALSE, TRUE, TRUE)) = 3 — a quick way to count matching elements.

Matrices

Creating & accessing matrices

A matrix is a 2-dimensional structure. All elements must be the same type. Indexing uses [row, column] — leave one side empty to select all.

X <- matrix(1:6, nrow = 2, ncol = 3, byrow = TRUE)
#      [,1] [,2] [,3]
# [1,]    1    2    3
# [2,]    4    5    6

dim(X)        # c(2, 3)  — rows, then columns
X[1, 2]       # 2        — row 1, column 2
X[2, ]        # 4 5 6    — entire second row
X[, 1]        # 1 4      — entire first column

# Building from vectors
A <- cbind(c(1,2), c(3,4), c(5,6))   # join as columns
B <- rbind(c(1,2,3), c(4,5,6))       # join as rows

# Naming
rownames(A) <- c("r1", "r2")
colnames(A) <- c("p1", "p2", "p3")
Function What it does
dim(X) Returns c(rows, columns)
nrow(X) / ncol(X) Number of rows / columns
cbind(x, y) Combine vectors as columns
rbind(x, y) Combine vectors as rows
colnames(X) Get or set column names
rownames(X) Get or set row names

Lists

Creating & accessing lists

Lists can hold elements of different types and lengths — unlike vectors or matrices. Access elements with $name or [[ ]].

L <- list(color = c("blue", "red"), size = 5, active = TRUE)

# Accessing content (returns the actual value)
L$color           # "blue" "red"
L[["color"]]      # same — "blue" "red"
L[["color"]][2]   # "red"

# Single brackets return a list, not the content
L["color"]        # a list of length 1 (not the vector!)
length(L["color"])   # 1
length(L[["color"]]) # 2

# Modifying & deleting
L[["size"]] <- 10     # change an element
L[["new"]]  <- "hi"   # add a new element
L[[3]] <- NULL         # delete third element
[ ] vs [[ ]]: Single brackets always return a list. Double brackets return the content. Use [[ ]] when you want to work with the value.

Dataframes

Creating & accessing dataframes

A dataframe is like a table: rows are observations, columns are variables. Unlike matrices, different columns can have different types.

Name   <- c("Ben", "Alice", "Daniel", "Charlie")
Year   <- c(1990, 1992, 1995, 1993)
Option <- c("Biology", "Physics", "Chemistry", "Mathematics")

df <- data.frame(First_Name = Name, Year = Year, Options = Option)

# Accessing columns
df$Year           # 1990 1992 1995 1993
df[["Year"]]      # same
df[, 2]           # same — all rows, column 2

# Accessing elements
df$Options[3]     # "Chemistry"
df[2:3, 3]        # "Physics" "Chemistry"

# Merging two dataframes
Full_Names <- data.frame(First_Name = c("Alice","Ben"),
                         Last_Name  = c("Parker","James"))

merge(df, Full_Names)          # Inner join — only matching rows
merge(df, Full_Names, all=TRUE) # Outer join — all rows, NA for missing
Function What it does
data.frame(...) Create a dataframe from named vectors
as.data.frame(X) Convert a matrix to a dataframe
dim(df) Rows and columns
colnames(df) Column names
str(df) Structure overview (types, first values)
merge(a, b) Join two dataframes on shared columns

Loops & Iteration

apply family & for loops

Mat <- matrix(rnorm(12), nrow = 3)

apply(Mat, 1, mean)   # mean of each ROW    (MARGIN = 1)
apply(Mat, 2, mean)   # mean of each COLUMN (MARGIN = 2)

x <- c(1:5)
sapply(x, sqrt)       # apply sqrt() to each element → returns vector
lapply(x, sqrt)       # same but returns a list

# For loop
for (i in 1:4) {
  print(i * 3)
}

# If / else
a <- 5; b <- 10
if (a < b) { print("a is smaller") } else { print("b is smaller") }
Function What it does
apply(X, 1, fun) Apply fun to each row of matrix/dataframe
apply(X, 2, fun) Apply fun to each column
sapply(x, fun) Apply fun to each element of vector/list → vector
lapply(x, fun) Apply fun to each element → list

Index Selection

which, %in%, is.na

x <- c(2, 8, 3, 7, 1)

which(x > 5)          # c(2, 4)  — INDICES where condition is TRUE
x[which(x > 5)]       # c(8, 7)  — VALUES at those indices

c("a","b","c") %in% c("b","d")  # FALSE TRUE FALSE
                                 # — is each element in the right-hand set?

is.na(c(1, NA, 3))    # FALSE TRUE FALSE
sum(is.na(x))         # count of NA values
Function / Operator What it does
which(condition) Returns indices where condition is TRUE
x %in% y For each element of x: is it anywhere in y?
is.na(x) TRUE for each NA element
na.omit(x) Remove NA values from a vector or dataframe

Lists

Creating & accessing lists (R: vectors)

Python lists use 0-based indexing and can hold mixed types. Use [ ] for indexing and slicing.

y = [9, 3, 7, 2]    # list of length 4
len(y)               # 4

# Indexing (0-based!)
y[2]                 # 7        — third element (index 2)
y[1:3]               # [3, 7]   — elements at index 1 and 2
y[:-1]               # [9,3,7]  — all except last

# Filter with list comprehension
[x for x in y if x < 5]      # [3, 2]
[x < 5 for x in y]           # [False, True, False, True]
sum(x < 5 for x in y)        # 2  — count matching

# Modifying
y[0] = 10            # replace first element (index 0)
Mixed types: Unlike R vectors, Python lists allow mixed types: [True, "hello", 3] stays as-is — no automatic conversion. Indexing starts at 0, not 1.

NumPy Arrays

Creating & accessing arrays (R: matrices)

NumPy arrays are the Python equivalent of R matrices. Requires import numpy as np. Indexing is 0-based.

import numpy as np

X = np.array([[1, 2, 3],
              [4, 5, 6]])
# Shape: (2, 3)

X.shape          # (2, 3)  — rows, then columns
X[0, 1]          # 2       — row 0, column 1 (0-based!)
X[1, :]          # [4 5 6] — entire second row
X[:, 0]          # [1 4]   — entire first column

# Building from vectors
A = np.column_stack(([1,2], [3,4], [5,6]))  # join as columns
B = np.vstack([[1,2,3], [4,5,6]])            # join as rows
Function What it does
X.shape Returns (rows, columns) as a tuple
X.reshape(r, c) Reshape to r rows and c columns
np.hstack((a, b)) Combine arrays side by side (columns)
np.vstack((a, b)) Stack arrays vertically (rows)

Dictionaries

Creating & accessing dicts (R: lists)

Dictionaries hold key–value pairs of any type. Use [ ] with the key to access values — there is no $ or [[ ]] in Python.

L = {"color": ["blue", "red"], "size": 5, "active": True}

# Accessing content
L["color"]           # ["blue", "red"]
L["color"][1]        # "red"   — second element (0-based)

# Check if key exists
"color" in L         # True

# Modifying & deleting
L["size"] = 10       # change a value
L["new"]  = "hi"     # add a new key
del L["size"]        # delete a key
R vs Python: R's L[["color"]] → Python's L["color"]. Square brackets always return the value directly in Python — no double-bracket distinction.

DataFrames

Creating & accessing DataFrames (R: data.frame)

Pandas DataFrames are the Python equivalent of R dataframes. Requires import pandas as pd.

import pandas as pd

Name   = ["Ben", "Alice", "Daniel", "Charlie"]
Year   = [1990, 1992, 1995, 1993]
Option = ["Biology", "Physics", "Chemistry", "Mathematics"]

df = pd.DataFrame({"First_Name": Name, "Year": Year, "Options": Option})

# Accessing columns
df["Year"]            # Series: 1990 1992 1995 1993
df.Year               # same — attribute-style access
df.iloc[:, 1]         # same — all rows, column index 1 (0-based)

# Accessing elements
df["Options"].iloc[2]    # "Chemistry"
df.iloc[1:3, 2]          # "Physics", "Chemistry"

# Merging two DataFrames
Full_Names = pd.DataFrame({"First_Name": ["Alice","Ben"],
                            "Last_Name":  ["Parker","James"]})

pd.merge(df, Full_Names)                    # Inner join — matching rows only
pd.merge(df, Full_Names, how="outer")       # Outer join — all rows, NaN for missing
Function What it does
pd.DataFrame({...}) Create a DataFrame from a dict of lists
df.shape Rows and columns as (r, c)
df.columns Column names
df.dtypes Data type of each column
df.describe() Summary statistics for numeric columns
pd.merge(a, b) Join two DataFrames on shared columns

Mat = np.random.randn(3, 4)

Index Selection

np.where, in, pd.isna

import numpy as np
import pandas as pd

x = np.array([2, 8, 3, 7, 1])

np.where(x > 5)          # (array([1, 3]),)  — INDICES where condition is TRUE
x[np.where(x > 5)]       # array([8, 7])     — VALUES at those indices

"a" in ["b", "d"]        # False  — membership test

Programming Languages and Their Working Environments

Before we start, it is important to understand the difference between the programming language itself and the program in which we write.

1. The Language: R and Python

R and Python are the “engines” behind your analysis. For your computer to understand what you want from it, you need to download the language as base software.

  • Python: Installed as a program from python.org.
  • R: Installed as “Base R” from the CRAN network.

Important: You will almost never open these programs directly. They “rest” in the background of your operating system and wait for commands.

2. The Tool: The IDE (RStudio & VS Code)

To actually write code, we use an IDE (Integrated Development Environment). This is your actual control center.

  • RStudio is the standard environment for R.
  • VS Code is the most popular environment for Python.

What Do You Need for Setup?

If you later want to work on your own computer, this is the correct order:

  1. Install the engine: Download Python or R (provides the “language”).
  2. Set up the workspace: Install an IDE like RStudio or VS Code (your workstation).
  3. Unpack the tools: Install so-called “packages” within the IDE. These are extensions for specific tasks, such as drawing biological diagrams.
TipOur Tip for Getting Started

To watch videos, follow the course and take quizzes, no installation is required. However, to work through the practical markdown files, you will need RStudio (for R) or VS Code (for Python) installed on your computer. Working with Markdown

In this course we do not use ordinary text documents or pure program code. In addition to this website, we work with Markdown files as an offline alternative.

In science, reproducibility (traceability) is crucial. Markdown allows us to do so-called Literate Programming: * We write our text (explanations, hypotheses). * We embed the actual code (R or Python) directly within it. * We let the computer render the document (in RStudio often via the Knit button).

The result is a finished document (HTML, PDF, or Word) in which the text, the code, and the resulting graphics are perfectly combined.

The Structure of a File

  1. The text: Regular text with simple formatting (**bold**, *italic*, # Heading).
  2. The code chunks: Blocks that begin with three backticks. This is where the actual code is executed. It is recommended to name each chunk — this keeps your document tidy and greatly facilitates troubleshooting.
  3. The YAML header: The area at the very top between the --- lines for title and author.

Focus: R and RStudio

R is a powerful language for statistical data analysis. We recommend that you also take the introductory courses at DataCamp to get a feel for the syntax. RStudio is an “Integrated Development Environment” (IDE) that helps you write code, visualize data, and save results.

The RStudio Interface

The interface is divided into four main areas:

  1. Source (top left): This is where you write your scripts and Markdown files. To create a new file, click on the New File icon (green plus) at the top left. Everything written here can be saved.
  2. Console (bottom left): Code is executed immediately here. For example, type 3 + 4 and press Enter — the result appears immediately. The console is ideal for commands that you do not need to save permanently.
  3. Environment (top right): All variables, lists, and datasets that you have created and defined during your session are displayed here.
  4. Files/Plots/Help (bottom right): Here you manage your files, view generated graphics, or search the help for functions (e.g., with ?matrix).

Python and VS Code

Python is a versatile and widely used programming language that is particularly well-suited for data analysis, machine learning, and scientific computing. We recommend that you also take the introductory courses at DataCamp to get a feel for the syntax. VS Code is a flexible development environment (IDE) that can be optimally adapted for Python through extensions.

The VS Code Interface

The interface is divided into four main areas:

  1. Editor (center): This is where you write your scripts and notebooks. To create a new file, click on the New File icon at the top left in the Explorer. Everything written here can be saved. The file extensions determine in which programming language you are writing and how the file can be used (.py/.ipynb for Python, .r for R, .md for Markdown).
  2. Terminal (bottom): Code is executed immediately here and files can be launched. Connections to clusters, communication with GitHub, or searching for files also work via the terminal. The terminal can be opened, for example, at the top right (3rd icon from the right).
  3. Explorer (left): Here you manage your files and folders. These are either stored locally on your computer or on a cluster.
  4. Control Center (far left): Here you can, for example, search documents for a keyword, connect and manage GitHub repositories, debug, install extensions, and manage remote connections (e.g., clusters).

First Steps in Programming

  • Assignments: In Python, values are loaded into variables with = (e.g., a = 10). Unlike R, there is no <- in Python.
  • Python as a calculator: Python is excellent for mathematical calculations. You can calculate directly with variables:

  • Case Sensitivity: Python is just as picky as R. hello is a different variable from Hello.

Getting Help:

Use the documentation directly in VS Code or online resources: Python Documentation W3Schools Python Tutorial Python for Data Science Handbook

  • Workspace: Use dir() to list all current variables and objects, and del a to delete a variable — Caution: del deletes irreversibly, so use it carefully!

  • Working Directory: With import os and os.getcwd() you can display the current directory; with os.chdir("path/to/folder") you change it.

Helpful Tips in the Editor

  • Autocomplete: VS Code automatically suggests functions, variable names, and brackets. Quotation marks "" and brackets () often appear automatically in pairs — this helps avoid syntax errors.
  • History: In the terminal you can scroll through your most recently used commands using the arrow keys (up/down).
  • Comments: Everything after a # is ignored by Python — just like in R. Use comments generously to explain your code.
